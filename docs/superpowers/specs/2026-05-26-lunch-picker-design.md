# 中午吃什么 — 随机小工具设计规范

## 概述

一个供微信内分享使用的 H5 页面，帮助用户（及其朋友）随机决定"中午吃什么"。核心体验：预设选项 → 点击抽签 → 老虎机滚动动画 → 结果揭晓 + 粒子特效。

## 用户流程

```
打开页面 → 看到选项列表 → 点抽签按钮
→ 老虎机滚动动画（约 2 秒）
→ 结果揭晓 + 粒子撒花特效
→ [再抽一次] 或 [编辑选项]
```

## 页面结构

单页面，由两个"屏幕"状态切换：

### 主页面

- 顶部文案：「又是纠结的一天…」等俏皮话
- 中部：老虎机滚动窗口（三列纵向滚动）
- 底部：「🎲 今天吃啥？」主按钮
- 点击后不可编辑选项（防动画期间改数据），滚动结束前禁用按钮

### 结果页

- 居中大字号：「命运选择了 兰州拉面 🍜」
- 俏皮话随机从内置数组抽取
- Canvas 粒子特效从中心炸开（彩色纸屑/星星）
- 「再抽一次」和「编辑选项」两个按钮

## 数据模型

localStorage key: `lunch-options`，结构：

```json
[
  { "id": "1712345678000", "name": "食堂自选", "emoji": "🍱" },
  { "id": "1712345678001", "name": "兰州拉面", "emoji": "🍜" }
]
```

- 首次打开加载默认列表（12 个选项，涵盖食堂、外卖、粉面、快餐、便利店、轻食等场景）
- 用户增删改后即时写入 localStorage
- 最少保留 2 个选项才能触发抽签
- id 用 `Date.now()` 生成

俏皮话数组从内置列表中随机抽取（约 8–10 条）。

## 动画设计

### 老虎机滚动（~2 秒）

- 三个竖列同时滚动，每列循环显示选项名 + emoji
- CSS `transform: translateY` + `transition` 驱动
- 降速时序：左侧 0.8s → 右侧 1.3s → 中间 2.0s
- 三列对齐同一结果后，停顿 0.3s，淡入切换到结果页

### 揭晓特效

- 结果文本：`scale(0)` → `scale(1)`，弹性缓出（cubic-bezier）
- Canvas 粒子：`requestAnimationFrame` 驱动，彩色圆点/星星从中心向外扩散，2 秒内淡出消失
- 粒子数量 ~60 个，颜色取自预设调色板

## 视觉风格

**方向：日系小清新**

- 色调：浅绿（`#81C784`） + 鹅黄（`#FFF9C4`） + 白色底色
- 圆角大、虚线边框、留白充足
- 选项标签：白底、浅色背景填充、虚线边框（`border: 1.5px dashed`）
- 按钮：实色绿底圆角、带柔和阴影
- 字体：系统默认中文字体栈，不做外部加载
- 参考意象：手帐便签、日系治愈风

## 技术实现

- 单文件 `index.html`，HTML + CSS + JS 全部内联
- 零依赖，无构建步骤
- 布局：Flexbox + `vh` 单位适配移动端
- 存储：localStorage
- 打开方式：本地直接浏览器打开；分享需部署到静态托管（GitHub Pages 等）

### 微信适配

- `viewport` meta 标签适配移动端视口
- 不需要微信 JS-SDK
- 响应式布局，覆盖 iPhone SE ~ Pro Max 及主流 Android 屏幕
